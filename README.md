## 🌟 Features

### 🎯 Core Search
- ✅ **BM25 Ranking** - Industry-standard relevance scoring
- ✅ **Semantic Search** - Vector embeddings for meaning-based search
- ✅ **Hybrid Search** - Combines BM25 + Semantic for best results
- ✅ **Advanced Ranking** - Multi-signal ranking (title, headings, freshness)
- ✅ **Snippet Generation** - Highlighted excerpts with context

### 🤖 AI & RAG
- ✅ **AI / RAG** - AI-powered answers with real citations
- ✅ **Grounded Answers** - Fact-checked, verified responses
- ✅ **Real Citation System** - Clickable sources with previews
- ✅ **AI Search Modes** - Web, AI, Research, Deep, Hybrid

### 🌐 Data & Crawling
- ✅ **106+ Wikipedia Articles** - 86,139 words indexed
- ✅ **Real-time Wikipedia Search** - 6+ million articles on-demand
- ✅ **Real-time Web Search** - DuckDuckGo integration
- ✅ **Custom Web Crawler** - Asynchronous with robots.txt support

### 🎨 Frontend
- ✅ **Pumpkin Theme** - Beautiful orange gradient design
- ✅ **Mode Selector** - Web/AI/Research/Deep/Hybrid
- ✅ **Autocomplete** - Real-time search suggestions
- ✅ **Related Searches** - Discover related topics
- ✅ **Responsive Design** - Works on all devices

### 🔒 Security & Performance
- ✅ **Rate Limiting** - Prevent API abuse
- ✅ **SSRF Protection** - Block internal network access
- ✅ **XSS Prevention** - Input sanitization
- ✅ **Redis Caching** - Lightning-fast repeated queries
- ✅ **Docker Support** - Containerized deployment

### 📊 Analytics & Evaluation
- ✅ **Search Analytics** - Track queries, latency, zero-result searches
- ✅ **Evaluation Metrics** - Precision, Recall, MRR, NDCG
